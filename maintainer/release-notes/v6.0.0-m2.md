# v6.0.0-m2: the Fusebase Flow 6.0 core, with `flow migrate` (pre-release)

For new projects and for projects on Flow 5.x. On a 5.x project, run `flow migrate`; do not run `install` over a 5.x tree.

Needs git, bash and Python 3.10+ with PyYAML (`pip install -r hooks/requirements.txt`). Get this release:

```
git clone --depth 1 --branch v6.0.0-m2 https://github.com/fusebase-dev/fusebase-flow.git fusebase-flow-6.0.0-m2
```

**New project** (the top level of a git repository):

```
python fusebase-flow-6.0.0-m2/maintainer/flow.py install --target <your-project> --providers claude,codex
```

**Project on Flow 5.x.** First run the dry run. It prints what it would remove, replace and add, and what it never touches, and changes nothing. The dry run runs the structural preflight; `--apply` runs the project's lint and typecheck before any change; so a dry run that exits 0 means the migration will go through only once those two also pass by hand. Then run the migration:

```
python fusebase-flow-6.0.0-m2/maintainer/flow.py migrate --target <your-project> --providers claude,codex
python fusebase-flow-6.0.0-m2/maintainer/flow.py migrate --target <your-project> --providers claude,codex --apply --go-ahead
```

`--apply` first checks everything that could stop it, and changes nothing if a check fails. It copies every file it removes or replaces into `.flow-migrate-<UTC time>/`. The migration lands as one commit through the new git hooks.

**Undo.** The end of `--apply` and the migration report in `docs/flow/ledger.md` print this block with the values filled in. Paste it into Git Bash at the project's top level, as one unit. It checks out the pre-migration commit on a new branch, puts the 5.x git hooks back and restores the untracked files the migration removed or overwrote. It stops at the first step that fails, and your shell stays open. The branch you migrated keeps the migration commit.

```
( set -e
  git checkout -b flow-5x-<UTC time> <the pre-migration commit>
  for h in pre-commit commit-msg pre-push; do if [ -f ".flow-migrate-<UTC time>/.git-hooks/$h" ]; then cp -p -- ".flow-migrate-<UTC time>/.git-hooks/$h" "$(git rev-parse --git-common-dir)/hooks/$h"; else rm -f -- "$(git rev-parse --git-common-dir)/hooks/$h"; fi; done
  while IFS= read -r p; do mkdir -p -- "$(dirname -- "$p")"; cp -p -- ".flow-migrate-<UTC time>/$p" "$p"; done < ".flow-migrate-<UTC time>/.migrate/untracked.txt"
)
```

This is a pre-release. CI gates it on Linux; the Windows (Git Bash) run reports but gates nothing until 6.0.0.

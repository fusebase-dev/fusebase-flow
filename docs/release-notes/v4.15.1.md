## Upgrade guidance

For a routine Fusebase CLI refresh, use:

```bash
fusebase update --skip-skills
```

If a full `fusebase update` replaces provider-managed files, restore Flow's overlay and previously authorized wiring with:

```bash
bash hooks/local/post-fusebase-update.sh
```

Automatic Git-hook restoration still requires prior Flow ownership proof. Use `bash hooks/local/post-fusebase-update.sh --wire-hooks` only when explicitly activating Flow hook wiring. Recovery preserves consumer and CLI-owned bytes and refuses ambiguous ownership or malformed overlay structure.

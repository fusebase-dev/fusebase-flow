## Corrections (each cites where it now lives)

1. **Select checks by what the change can break**; comment-only edits need syntax + the structural check over those lines, printed-text edits add the groups that grep the old text, not every runtime group (`maintainer-execution.md` step 3).
2. **A contended local host is not evidence**: check load before a run over 10 minutes; leave heavy groups to hosted CI; a group still producing rows on a contended host is not rerun there; one that stops producing rows is a Timeout (step 3, Failure handling, Execution).
3. **Review concurrently with checks**, unless the review runs its own reproductions beside a long local run (step 4).
4. **No pre-tag full run, local or hosted, of the release commit**; an operator exception covers one release only (step 2, Checks and evidence; `maintainer-testing.md`).
5. **A pre-existing intermittent gate failure is not fixed inside the release**: eligibility is a `git diff --quiet <last published tag> <sha> --` over the failing test and what it exercises; file it and offer "re-run the failed jobs once" or "fix and ship the next version" with costs; this row overrides the essential-failure and tooling-error rows and is the one re-run `PUBLISHING.md` now allows besides transient environment failures (Failure handling).
6. **Trials only where the code does not already show the mechanism**; they declare a time bound and avoid contended hosts (step 3).
7. **Verification plan and ETA in chat** before any wait over ten minutes (step 3).

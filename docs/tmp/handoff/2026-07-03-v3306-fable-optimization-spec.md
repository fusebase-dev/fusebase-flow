### F3 — Adaptive poll in the bounded-run reap loop (MED risk — hottest safety code; DO LAST, real 2–5 min/gate)

Add `_ffhc_nap SECS` builtin nap: Tier1 = `read -t` on an RW-opened FIFO (never EOF/blocks-on-open), PROBED once at init (mkfifo + timed read; accept only if a 0.05s nap really blocks ≥0.04s — an EOF-broken fd returns instantly → reject; LIVE-PROVEN on this host: 205ms for a 200ms request, zero spawns); Tier2 = external `sleep` (today's mechanism). When EPOCHREALTIME unavailable OR nap-probe fails ⇒ else-branch is LITERALLY today's `sleep 1; waited=$((waited+1))` (zero regression on any other host). Optional/defer: job-fence confirm loop (:354) sleep 0.1 → nap (opt-in path only).

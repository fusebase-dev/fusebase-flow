## OVERRIDING SAFETY CONSTRAINT (read first — REVISED per Codex plan review, verdict RECONSIDER→folded)
WS2-hard targets a failure mode (Cummings-class: ac3d SIGKILL-grace doesn't fire, native descendant blocks past deadline) that **CANNOT be reproduced on this publish host** (WS2-core already works here; 26 timeout tests pass). The plan review flagged auto-enable + a PowerShell timeout-reimplementation as BLOCKER-level overreach on the framework's most load-bearing function. **Folded design (non-negotiable):**
1. **DEFAULT OFF.** `FFHC_USE_JOB_OBJECT` default = **0** (forced opt-in). No `auto` default in v3.30.4. So on EVERY host the default path is byte-behavior-unchanged WS2-core — zero regression risk by construction. Consumers with the Cummings problem set `FFHC_USE_JOB_OBJECT=1` to opt in.
2. **OUTER FENCE, not a reimplementation.** The Job Object is an OUTER HARD-KILL FENCE around the EXISTING `run_with_timeout`/`timeout -k` root — it does NOT reimplement timeout in PowerShell. The existing path keeps producing the 124/137 rc + stdout capture + T8/T12/T17/T18 stdin semantics; the Job Object only guarantees the deadline-kill reaches ALL native descendants and is scoped (can't hit the harness/caller/other session). Never put load-bearing argv/stdin/rc handling in bash→PowerShell string quoting; pass any payload via a temp `.ps1` + a structured args file, not an inline `-Command` string. If `stdin_mode=inherit`, DISABLE the job branch (fall to WS2-core) unless stdin passthrough is proven.
3. **NO-RERUN fallback.** Fallback may re-run the command ONLY on a **pre-launch** probe/helper-setup failure. A helper failure AFTER the child launched must clean up (terminate the job) and return a bounded rc — NEVER re-execute the command (no double-run / orphan).
4. **Bounded probe + helper.** The one-time capability probe AND the helper are themselves bounded by the WS2-core watchdog so they can never hang before the fallback exists.
5. **Prove it ran.** The publish host IS MSYS and HAS `powershell.exe` — so the job-path MECHANISM smoke MUST actually run here (non-skipped): rc-preserved, tempfile capture, 124-on-timeout, 137-on-hard-kill, concurrent-sibling-survives, forced-probe-failure→clean-fallback. Only the Cummings-specific ac3d→rc137 *reliability* stays consumer-gated. Do NOT ship a job branch that never executed.
6. **POSIX untouched.** `run_with_timeout` POSIX body byte-identical (add a hash-gate before/after); job branching lives ONLY inside `_ffhc_tempfile_capture` after the tempfile/T8 setup, guarded by `ffhc_is_msys`.

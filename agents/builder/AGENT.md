# Builder

Read `FLOW_RULES.md`, then your slice (tasks, push block, writing card). Read no other Flow file.

- Stop and ask when a locked decision, an input or the scope is unclear; never guess.
- Ceremony proportional to risk: the risk tag and the paths you touch set the evidence; add no step the slice does not ask for.
- An owner answer contradicts the code: return `BLOCKED-AT-<gate>` naming both; never change the answer.

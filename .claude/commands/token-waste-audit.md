# /token-waste-audit

Invoke the **token-economy** skill's measurement path (`flow-skills/token-economy/SKILL.md` § Measure it).

1. Run `python hooks/local/token-waste-audit.py` (if `python` is missing, run `python3 hooks/local/token-waste-audit.py`). Optional args: `--last N` (top-level sessions; each brings its direct and workflow agents), `--dir PATH` (transcript dir override), `--main-only` (old main-session scope), `--probe-command CMD` (repeatable — a documented probe command from this ticket's own gate, so its reruns can be auto-classified).
2. Read the report it wrote (`state/audit/token-waste-audit-<date>.md`) — main totals + sub-agent aggregate (agents, workflows, requests, output, cache read/creation), top-10 agents by cache read with workflow id, top text-result sinks and candidates named by originating transcript. Parse `agent-*.jsonl` under `<sid>/subagents/` and `workflows/wf_*/`; exclude `journal.jsonl`. This includes **large-output compression candidates** (tool results ≥20k chars from any output-producing tool — built-in or MCP — whose size suggests scoped reads, narrower commands, report files, jq/grep/filtering, targeted tests, shorter tracebacks, or pointer-backed summaries before reasoning over the content) and **repeat-output candidates** (the same large body re-sent across turns, matched by a one-way fingerprint — never the content — that should be referenced by its handle instead of re-pasted).
3. Read the image table: token **estimates** use PNG IHDR / JPEG SOFn dimensions, long edge ≤1568 px, ≈width×height/750; unknown dimensions = 1600. Images never enter text sizes, `large-output` or `repeat-output`. `image-reread` = identical image bytes delivered ≥2× in one transcript (TE-21/TE-02 candidate); changed bytes at the same path = re-capture. Attachment lines and hook output are excluded. Read the **auto-classified** section too — it is deliberately separate from the live findings so a dismissal neither buries nor inflates the count. Each row names the rule that fired (`growing-source-tail` / `possible-FR-10-triple`) and the evidence behind it; both rules are conjunctive and label-don't-delete, so re-open any dismissal whose evidence you do not believe. Report the terminal state the run printed — candidates found · all auto-classified · no candidates above thresholds · no transcripts/parse failure — and never read the last two as "clean" without saying which one it was.
4. Interpret every finding as a CANDIDATE that MAY indicate the cited FR-26 rule. Confirm or dismiss each one against the report header's false-positive classes before calling it waste — for `large-output` that includes an intentional first read of a large file (to hold its invariants), a warranted FR-18 full-`Write` supersede (structure/mode/ticket change or most sections changed — a targeted `Edit` is the default primitive) / mirror regeneration, generated output that is itself the task's subject, deliberate FR-10 reproduction evidence, and a one-time large diagnostic report written then read once.
5. Output a Mode A summary in chat: totals table, top sinks, confirmed-vs-dismissed candidates (by class, incl. large-output). Do not paste message/thinking/tool-result text, image data or hook output (the report excludes them).
6. Recommend concrete fixes, each citing the FR-26 rule row it applies — scoped reads, re-read only after invalidation, two-strike diagnose via `zoom-out`, record-then-read per `smoke-testing` § Verification cost discipline (`flow-skills/token-economy/SKILL.md` § Rules); map `large-output` and `repeat-output` candidates to `flow-skills/token-economy/SKILL.md` § Context compression discipline (extract/scope/filter; reference an in-context body by its handle instead of re-sending it; pointer-backed summaries with a retrieval handle).

The **first report/stdout section** attributes main/sub-agent cost to cache read, cache write 5m/1h, uncached input and output, priced per request's model using `hooks/local/token_waste_audit/costing.py`: **list-price estimate (rates as of 2026-10); subscription billing differs**. Unknown/`<synthetic>` models stay in token totals with an unpriced-request line; no guessed rates. Unsplit creation is priced at 5m.

Read **context residency** (peak/average/requests, `compact_boundary` compactions, top-10 transcripts by cache-read USD): one `context-residency` signal per session when transcripts peaking ≥500k hold ≥50% of cache-read cost. **Cache rewrite after expiry** summarizes count/tokens/USD by main/sub-agent scope: creation ≥100k after a start-to-start gap > this request's explicit creation TTL (1h split >0, otherwise 5m split >0; unknown skipped). Polling rows count wakes as the issuing requests after the first issue, with their context sum (read + creation + input) and USD at each request's cache-read rate. A request starts at its preceding user/tool_result line (the send), else its first streamed line. `context-residency` / `cache-rewrite` are cost signals, not proof that the work was unnecessary.

One **Sub-agent rewrites at 5-60 min gaps** line per session gives the share of sub-agent cache-write tokens re-written after a 5–60 min gap on the 5m TTL (only the prefix cached before the gap counts; new-turn tokens are written under either TTL), beside the 1h-TTL break-even 0.75/(2 - r) (r = the model's cache-read ÷ input; the reads that replace avoided writes are counted), or a cost-weighted 1h-vs-5m USD comparison when several priced models mix; the share is a lower bound (rewrites under 100k creation are not counted). **Advisor calls** lists calls, observed waits, and `advisor_message` iteration tokens/USD by model, main vs sub-agents; top-level usage omits those iterations, so Cost attribution adds them as an `advisor` row. **Wall time (FR-27 lens; candidates, not verdicts)** lists tool calls in flight ≥10 min: Bash/PowerShell = stall candidate, Task/Agent/advisor = delegation wait, other tools = tool wait; never a hang verdict (`liveness-discipline` decides).

Live rows are ordered by USD, unpriced last, each marked `observed` (recorded usage × list price: `cache-rewrite`, `context-residency`) or `estimated` (sizes ÷ 4 or context × cache-read rate) (text/image payloads at input rate; rewrite payloads at output rate; estimates overlap, not avoidable-spend totals). Each session caps `large-output`, `repeat-output` and `cache-rewrite` at 10 rows per class across main + agents, with **"N more suppressed (session cap)"**; other classes are retained in full. Cache-rewrite summaries include suppressed matches.

Non-Claude surfaces (Codex/Cursor/Copilot/Gemini): transcript metrics are unavailable — invoke the `token-economy` skill and use its repo-side fallback (the parser prints it and exits 0).
